# ROS 2 Workspace

Ubuntu 24.04 / ROS 2 Jazzy workspace owned by Santhosh.

Source packages:

- `so_arm_100_hardware`: SO-101 serial hardware interface, robot model, meshes,
  utilities, and controller configuration.
- `lerobot_moveit`: MoveIt configuration and motion client.

Generated `build`, `install`, and `log` directories are intentionally excluded
from Git.
